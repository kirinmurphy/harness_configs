# Managed By Roborepo

Stable Gemini config is version-controlled in:

this repository.

Prefer editing the repo copy, not ad hoc files in `~/.gemini`.

If a Gemini config path is added or changed directly under `~/.gemini`, update this repo so the change is version-controlled. Use `./scripts/sync-from-home.sh` only for intentionally capturing selected live config back into the repo.
